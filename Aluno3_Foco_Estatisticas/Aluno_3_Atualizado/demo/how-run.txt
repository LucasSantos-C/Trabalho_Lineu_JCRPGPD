COMO EXECUTAR O PROJETO

DEMONSTRAÇÃO INDIVIDUAL DO ALUNO 3
1. Abra a pasta raiz do projeto no VS Code ou abra diretamente a pasta demo.
2. Aguarde o VS Code/Maven carregar as dependências do pom.xml.
3. Execute MainAluno03.java.
4. Esse programa apresenta uma única tabela com, para cada categoria:
   - quantidade de transações;
   - valor total;
   - valor médio;
   - maior transação.
5. Antes da tabela, compara os resultados sequencial, ExecutorService e
   ExecutorService + Affinity. A conferência deve indicar [OK] para as duas
   implementações paralelas.

O padrão é 10.000.000 transações e 4 threads. Se quiser testar um volume menor,
informe dois argumentos na configuração de execução do VS Code. Exemplo:
   1000000 4

BENCHMARK E GRÁFICOS — MÓDULO DE DESEMPENHO / ALUNO 4
1. Execute MainBenchmark.java para medir tempos, speedup e eficiência.
2. O programa gera resultados_benchmark.csv na pasta demo.
3. Para gerar os gráficos, instale Python e Matplotlib. Depois, no terminal
   dentro de demo, execute:
      python -m pip install matplotlib
      python gerar_graficos.py
4. Os PNGs são criados na pasta demo/graficos.

O MainBenchmark está configurado para 1, 5 e 10 milhões. Não aumente para
50 milhões sem rever a estratégia de memória: o gerador atual mantém todos os
objetos Transacao em memória e já apresentou OutOfMemoryError nesse volume.
